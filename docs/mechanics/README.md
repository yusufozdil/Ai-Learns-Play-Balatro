# Mechanics notes

Rule references collected by agents. **Every rule needs a source.**

- One file per topic (`hands.md`, `scoring.md`, `cards.md`, `jokers.csv`, `bosses.md`, …).
- Each rule/number is followed by its source URL (Balatro Wiki/Fandom or another public page) and, if
  sources disagree, both versions plus the decision taken and why.
- Describe mechanics in your own words. Do **not** paste game source code, game text dumps or assets.
- Uncertain items are marked `UNVERIFIED` and tracked as open items.
- Rule descriptions are paraphrased from the community Balatro Wiki (balatrowiki.org, linked per rule) and verified against the simulator.
