# Skip tags

Sources: TG = https://balatrowiki.org/w/Tags ; Orbital https://balatrowiki.org/w/Orbital_Tag ; blinds page https://balatrowiki.org/w/Blinds_and_Antes . [mem] = original game behaviour recalled, UNVERIFIED.

## Rules
- A tag is gained by skipping a Small or Big Blind; Boss Blinds cannot be skipped [TG, Blinds_and_Antes]. Tags stack, trigger oldest first [TG].
- Assignment: wiki gives no procedure. Equal chance per tag, repeats allowed even in the same ante [TG]. Recommend [mem]: when blinds are set for an ante, each of Small/Big gets one tag drawn uniformly from tags whose min ante <= current ante, drawn from the seeded RNG and visible before skipping. UNVERIFIED.
- Ante 1 excludes nine tags (min ante 2): Negative, Standard, Meteor, Buffoon, Handy, Garbage, Ethereal, Top-up, Orbital [TG]; 15 remain.
- Unlock conditions (Rare needs Blueprint, edition tags need that edition discovered) are profile-level [TG]; assume all unlocked.
- Pack tags open their pack right after skipping [mem] UNVERIFIED (wiki: timing "not stated"). Other timing per TG column.
